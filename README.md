# 🧮 Health & BMI Calculator

A responsive web-based **Health & BMI Calculator** built using **HTML, CSS, and JavaScript**.

This project provides separate calculators for **Adults, Children & Teens, and Pregnancy**, making it more useful than a basic BMI calculator.

## ✨ Features

### 👤 Adult BMI Calculator

- Calculates BMI using height and weight.
- Height can be entered in centimeters.
- Weight can be entered in kilograms.
- Displays BMI instantly.
- Shows BMI category:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Includes a visual BMI scale.
- Input validation.
- Reset button.

### 🧒 Children & Teen BMI Calculator

- Designed for children and teenagers aged **2–19 years**.
- Takes:
  - Age
  - Sex
  - Height
  - Weight
- Calculates BMI.
- Explains that children's BMI should be interpreted using **BMI-for-age percentiles** rather than adult BMI categories.
- Displays the standard percentile categories:
  - Underweight
  - Healthy Weight
  - Overweight
  - Obesity

### 🤰 Pregnancy Weight Gain Guide

- Uses pre-pregnancy height and weight.
- Calculates pre-pregnancy BMI.
- Takes the current pregnancy week.
- Provides a general recommended total pregnancy weight-gain range based on pre-pregnancy BMI.
- Displays different ranges for:
  - Underweight
  - Normal Weight
  - Overweight
  - Obesity
- Includes a medical disclaimer.
